Keyboard Shortcuts

  • Ctrl+C / Cmd+C - Copy cell
  • Ctrl+X / Cmd+X - Cut cell
  • Ctrl+V / Cmd+V - Paste cell
  • Ctrl+Z / Cmd+Z - Undo
  • Ctrl+Y / Cmd+Y / Ctrl+Shift+Z - Redo
  • Enter - Move down
  • Tab - Move right
  • Arrow keys - Navigate
  • Esc - Cancel edit
